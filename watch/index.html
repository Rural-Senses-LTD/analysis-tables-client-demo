Read the transcript

Summary Tables help you compare groups and understand the numbers behind them. Let's start with a simple crop comparison.

Open Results by crop. Each row is a crop, with Baseline and Endline side by side. The values show average yield, with units and the number of records used.

The data sources sit below the table, so it's clear which records are included.

Open Filters, then Add filter. Choose filter lets you search all categories and measurements, including fields that aren't displayed in the table. Let's search for Region.

Choose Region from Endline. Click Unselect all, select Amhara, and apply. The table now shows only that region, with its filter above.

To filter by a measurement, add another filter and search for Land size. Choose the Endline measurement.

Set the minimum to zero point one and the maximum to one. Mean and Median help you read the distribution. Apply the range to update the results.

Click a value to see its contributing source records. Baseline and Endline have separate columns, with the identifiers, categories, and measurements used in the table.

Choose View record to inspect one response. View raw data is here when you need to continue to the underlying source.

Close the record and return to the tables. Open Performance by area, then use the top scrollbar to move across columns. The row labels stay in place.

To build your own view, choose New table and give it a name. We'll compare yield by crop and irrigation type.

Add Crop as the row category. Then add Irrigation Type as the column category. Both choices are at the top of the creation window.

Keep Yield per hectare and Mean. For data sources, keep Endline selected and clear Baseline.

Check the live preview, then choose Create table. Your new table appears alongside the saved views.

Open Categories and Measurements to review the building blocks. The yield definition shows which source questions supply the numbers and how they are calculated.

Start with a table, focus on the group you need, and check the details.
