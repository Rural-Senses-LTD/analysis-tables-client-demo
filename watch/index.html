Hi! Today I’d like to show you the new feature from Rural Senses – Summary Tables.

Summary tables are an easy way to review large volumes of data. You can compare averages and totals across different groups, explore the individual responses behind each cell, and turn the table into charts and add them to reports or to your home page dashboard.

In this video, I will first walk you through the basic features – reviewing an existing table, modifying it, creating charts and adding them to reports. Then I’ll show you the more advanced features: creating tables from scratch and creating new table categories.

We’ll start by exploring saved tables.

Let’s look at a real example – a farmer survey dataset that includes data on yield and income.

The project already has a few default tables – each default table appears in its own tab and is always accessible.

Let’s look at this table that summarizes the total cabbage yield by woreda.

You can look at the data behind any number.

Clicking on each cell will show me the actual values that were used to calculate its value, and I can look into each of them, and also click “open raw data” to navigate to the full survey where you can see the editing history and make your own edits.

Let’s modify the table to explore a different view.

Modifying the table is easy – simply open the table settings – you can change the definitions. For example, look at averages instead of totals, and split by any of the available categories – for example drip usage in addition to Woreda.

Next, let’s turn the table into a chart.

Any table can be used to create a chart. Click on the “Create chart” button and select the rows and columns you want to include.

You can add your tables and charts to a report.

Keep your preferred tables and graphs accessible by adding them to a report or to your home screen.

Now that we’ve covered the basics, let’s look at some of the advanced features that give power users complete freedom in creating and managing tables.

Now, let’s create a table from scratch.

To build a new table, choose New table and give it a name you’ll recognize later.

Table creation follows the format of a sentence. For example: Show me the average income for each crop, split by woreda and drip usage.

You can see a preview of the table format and adjust if needed.

Click create table, and the new view appears. It’s ready to explore the same way as the existing tables.

You can also create your own categories and measurements.

The “building blocks” of the tables are categories and measurements. Categories define the rows and column titles in your table, for example Crop, Woreda or Drip use. Measurements supply the numbers inside the cells, like yield and income.

You can create new categories and measurements yourself. Let’s see how we can create the measurement “yield per dunam”.

Next to Categories & measurements, click Manage

Then click “Create category or measurement.” Choose “Numeric measurement,” and then Continue.

Now we will select the survey questions that will allow us to define “yield per dunam”. In this example these are “ Total cabbage harvested this season” and “Area planted on this plot (dunam)”.

I will click continue and now both the yield and the area questions are variables, and I can use them to build my measurement using a formula like in Excel, and define yield divided by planted area in dunam.

Now I will add a title and definition and this measurement is ready to be used.

Now I can create a new table, or edit an existing one using the new “Yield per dunam” measurement.

So that’s the new Summary Tables feature — a new way to review large volumes of data. We’re very excited about this feature and can’t wait to hear your feedback.
